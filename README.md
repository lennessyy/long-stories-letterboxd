# Long Stories for Letterboxd

A small web app for turning Letterboxd reviews into Instagram Story images.

Paste a Letterboxd review URL, generate story-sized layouts, preview the options,
and save or share the image. The templates are designed for both short and long
reviews, with layouts tuned for readable review text, film imagery, ratings, and
reviewer attribution.

The app is deployed at:

https://stories.lennyc.me
